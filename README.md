# MATLAB | Simulações e Modelagem de Sistemas

Repositório dedicado ao desenvolvimento de rotinas computacionais, algoritmos numéricos e simulações em MATLAB aplicadas a problemas de Engenharia Elétrica. 

O foco deste repositório é documentar a implementação de modelos matemáticos, análise de sistemas dinâmicos e processamento de sinais, servindo como base para projetos acadêmicos e validações teóricas.

## Estrutura do Repositório

O código-fonte está organizado em módulos baseados em áreas de estudo e aplicação:

* **`/Sinais e sistemas`**: Scripts voltados para a análise de sinais contínuos e discretos. Inclui modelagem de sistemas lineares invariantes no tempo (LTI), convolução, e aplicação de transformadas (Laplace e Fourier) para análise no domínio da frequência e estudo de motores.
* **`/LAB Controle`**: Rotinas do laboratório de Sistemas de Controle. Contém simulações de plantas dinâmicas, análise de estabilidade, resposta a degrau, lugar das raízes (Root Locus) e projeto de controladores para malhas fechadas.
* **`/Gorjeta`**: Implementação prática de Lógica Fuzzy (Fuzzy Logic). Contém a modelagem de um sistema de inferência não-linear baseado em regras lógicas para tomada de decisão (avaliando qualidade da comida e do serviço para determinar o valor da gorjeta).

## Tecnologias e Toolboxes Utilizadas

* MATLAB
* Control System Toolbox
* Signal Processing Toolbox
* Fuzzy Logic Toolbox
